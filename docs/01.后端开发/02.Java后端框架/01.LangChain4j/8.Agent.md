# Agent

请注意，“Agent” 是一个非常宽泛的术语，具有多种定义。

## 推荐阅读

- [构建高效的 Agent](https://www.anthropic.com/research/building-effective-agents) - Anthropic

## Agent

大多数基本的“代理（agentic）”功能可以通过高级 [AI 服务](7.AI%20Services.md) 和 [工具](./9.Tools.md) API 构建。

如果需要更高的灵活性，可以使用低级别的 [ChatLanguageModel](./3.Chat%20and%20Language%20Models.md)、[ToolSpecification](9.Tools.md) 和 [ChatMemory](4.Chat%20Memory.md) API。

## 多 Agent

LangChain4j 不支持类似 [AutoGen](https://github.com/microsoft/autogen) 或 [CrewAI](https://www.crewai.com/) 这样的 *高级* 抽象，用于构建多代理系统。

然而，您仍然可以使用低级别的 [ChatLanguageModel](./3.Chat%20and%20Language%20Models.md)、[ToolSpecification](9.Tools.md) 和 [ChatMemory](4.Chat%20Memory.md) API 构建多代理系统。
