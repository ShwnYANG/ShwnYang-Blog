# 现代密码学导论

## 简介

《现代密码学入门》（Introduction to Modern Cryptography）是Jonathan Katz和Yehuda Lindell共同编写的一本现代密码学教材，第三版于2019年出版。该书涵盖了现代密码学的基本概念和技术，包括对称加密、公钥加密、哈希函数、数字签名等方面的介绍。此外，该书还涉及一些高级话题，如多方计算和同态加密。
[点击下载原书： Katz 和 Lindell 的《Introduction to Modern Cryptography》 (2021)](https://cos.ywenrou.cn/blog/imagesKatz%20%E5%92%8C%20Lindell%20-%202021%20-%20Introduction%20to%20modern%20cryptography.pdf)

![](https://cos.ywenrou.cn/blog/images20230926145155.png)

## 内容概要

该书主要分为两部分：

1. 基础密码学：介绍对称加密、公钥加密、哈希函数、消息认证码等基本密码学概念和技术。

2. 高级密码学：介绍多方计算、同态加密、零知识证明等较为高级的密码学内容。

除此之外，该书还包括一些附录，例如数论基础、信息论、复杂性理论等内容。



**《现代密码学入门》是一本非常值得推荐的现代密码学教材，无论是对于密码学专业的学生，还是对于从事安全领域的从业人员都是一本非常有价值的参考书。以下是本人结合互联网资源进行的中文翻译，如有不当敬请指出，谢谢！**
